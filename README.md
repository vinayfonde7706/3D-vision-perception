# 3D-vision-perception
Here I am Integrating the TOF (Time of flight) sensor with a 2D cam to get a 3D perception of what the cam is seeing.
Initially I am starting with a normal 1D TOF, and will get the data of it but soon after i will use open cv to see a particular object and then find the distance of it using tof.
If this works well then we'll move towards using the Grid based Tof,which doesn't just scan at 1 point but captures a larger area, so eventually i can get the distances of all object which are there in the cams FOV.
